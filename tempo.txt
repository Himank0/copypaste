Includes Bulk Task Create, Bulk Task Update and access to Pending & Terminated Partners.

## Supporting Notes

### Dealer Search (Active / Pending / De-commissioned)

- Users can open the Dealer Record via the **Open** button.
- Users can obtain a CSV extract of basic Partner details, via the **Export Search Results** button.
- Super Users, by clicking the radio button to the left of the Dealer Name, can initiate a new Task for the Partner via the **Batch Initiate Task** button.
- Super Users, by clicking the radio button to the left of the Dealer Name, can terminate (de-commission) the Partner via the **Terminate** button.

### Dealer Search (Channel Type / State)

- Users can open individual Dealer Records via the **Open** button.
- Users can obtain a CSV extract of basic Partner details, via the **Export Search Results** button.
- Super Users can initiate a new Task for any of the listed Partners, via the **Batch Initiate Task** button.
- Super Users can terminate (de-commission) any of the listed Partners, via the **Terminate** button.

### Document Search

- Users can open the Dealer Record via the **Open** button.
- Users can obtain a CSV extract of all contract documents held by the Partner (including lifecycle status), via the **Export Search Results** button.
- For bulk update: Super Users, by clicking radio button/s to the left of the Dealer Name, can supersede or terminate the document for the tagged Partners using the **Supersede** or **Terminate** buttons.

### Task Search

- Users can open the Dealer Record via the **Open** button.
- Users can obtain a CSV extract of all Partners with the defined Task (including current Task Status), or all Tasks issued to a Partner (with Document, Module, Version details), via the **Export Search Results** button.
- Super Users can update the Task Status for tagged Partners using the **Batch Manage Task** button (except Tasks at Filed (Complete) status).

### Super User – Partner Termination (Immediate)

- Super Users can de-commission (terminate) a Partner immediately by ticking the check button/s to the left of the Dealer Name, selecting the current date in the **Date Select** field and clicking **Terminate**.
- A prompt confirms the intent to terminate. On acknowledgement, the Partner moves from Active status to De-Commissioned (Terminated) status.
- The same Dealer Record can return to Pending status if a new task is allocated and the related executable contract document is awaiting signature. Once signed, the Partner moves from Pending back to Active.

### Super User – Partner Termination (Future Date)

- Super Users can de-commission a Partner at a future date by ticking the check button/s, selecting a future date in the **Date Select** field and clicking **Terminate**.
- A prompt confirms the intent. On acknowledgement, the Dealer Record is updated to reflect the pending termination for the Record and all documents contained therein. All "active" documents for the Partner are shaded **red** as a visual indicator of a pending termination.
- Once the future termination date arrives, the Partner is automatically moved from Active status to De-Commissioned (Terminated) status.
- The same Dealer Record can return to Pending status if a new task is allocated and the related executable contract document is awaiting signature.

### Super User – Termination via Code Type & Codes Fields

- Super Users can terminate immediately or at a future date by ticking check button/s to the left of the Dealer Name, choosing the date in the **Date Select** field and clicking **Terminate**.
- **Immediate termination:** a confirmation prompt is shown; on acknowledgement the Partner moves from Active to De-Commissioned (Terminated).
- **Future date termination:** a confirmation prompt is shown; on acknowledgement the Dealer Record reflects the pending termination and all "active" documents are shaded red. On the termination date the Partner automatically moves to De-Commissioned (Terminated).
- The same Dealer Record can return to Pending status if a new task is allocated and the related executable contract document is awaiting signature.

### Search Fields Not Required (4a–4f)

- **SD Code, Dealer Code, Premise Code** – not required, as the Keyword Search field covers these criteria.
- **Account Manager dropdown** – not required.
- **Business Unit check boxes** – not required.
- **Dealer Under Negotiation check box** – not required, as the existing New Dealers (Pending) check box covers this criterion.

## Field Inventory – Advanced Search

> **Note on columns:** The `Field Type` column has been verified against a screenshot of the live Advanced Search screen. The `Datasource`, `Business Validation` and `Static / API Source` columns are **derived** from the behaviour described in the source document, which does not specify data sources, validation rules or whether values are statically configured versus API-driven — they are a starting point for design review and should be confirmed against the CMD data model before being treated as authoritative.

### 1. Global & Keyword Search Fields

| Field Name | Field Type | Datasource | Business Validation | Static / API Source |
|---|---|---|---|---|
| Search box 1 (top right-hand corner) | Text field | Dealer Record master data (Active status only) | Free text; matches Name, ABN, suburb. Restricted to Dealer Records at "Active" status | API – dealer search query |
| Keyword Search (Search box 2) | Text field | Dealer / Document / Task indexes depending on selected search mode | Free text. Matches Name, ABN, suburb, Dealer Code, Dealer Ref for Dealer mode; partial Document Name for Document mode; partial Task Name for Task mode | API – keyword search query |
| Search Type selector (Dealer / Document / Task) | Dropdown | Fixed enumeration | Exactly one mode must be selected; drives which result columns and filters are shown. Defaults to Dealer | Static – hard-coded list of 3 values |
| New Dealers (Pending) check box | Checkbox | Dealer Record status flag | Optional. When ticked, includes Dealer Records at "Pending" status in results | Static toggle applied as an API filter |
| Terminated check box | Checkbox | Dealer Record status flag | Optional. When ticked, includes Dealer Records at "De-commissioned (Terminated)" status in results | Static toggle applied as an API filter |
| Dealer Under Negotiation check box | Checkbox | Dealer Record status flag | Optional. Returns all Pending Partners. **Redundant** – duplicated by the New Dealers (Pending) check box | Static toggle applied as an API filter |

### 2. Code Search Fields

| Field Name | Field Type | Datasource | Business Validation | Static / API Source |
|---|---|---|---|---|
| SD Code | Text field | Super Distributor Code held on the Dealer Record (sourced from Commissions team) | Numeric, exactly 4 digits. **Redundant** – covered by Keyword Search | API – dealer search query |
| Dealer Code | Text field | Dealer Code held on the Dealer Record (sourced from Commissions team) | Numeric, exactly 5 digits. **Redundant** – covered by Keyword Search | API – dealer search query |
| Premise Code | Text field | Premise Code held on the Dealer Record (sourced from Commissions team) | Numeric, exactly 4 digits. **Redundant** – covered by Keyword Search | API – dealer search query |
| Code Type | Dropdown | Fixed enumeration of code categories (e.g. "Dealer Ref #") | Defaults to "Select existing". One value must be selected before the Codes field is used; determines how Codes values are interpreted | Static – configured drop down list |
| Codes | Textarea (multi-line, multi-value) | User-entered list of identifiers, resolved against Dealer Records | Accepts one or more codes matching the selected Code Type. Values must resolve to existing Dealer Records to appear in Search Results | API – bulk lookup by code |

### 3. Dealer Attribute Filters

| Field Name | Field Type | Datasource | Business Validation | Static / API Source |
|---|---|---|---|---|
| Channel | Dropdown | Dealer Type / Channel reference data (e.g. T-Partner LOTE) | Single selection; defaults to N/A. Returns all Partners in the chosen channel | API – reference data lookup |
| State | Dropdown | State held against the Partner's principal business address | Single selection; defaults to N/A. Combines with status check boxes to scope Active vs Pending/De-Commissioned | Static list of states; applied as an API filter |
| Account Manager | Dropdown | Account Manager register in Manage Account Managers | Single selection; defaults to "Any". **Not required** – register is not maintained, as Channels keep their own Account Manager records | API – Account Manager reference data |
| Business Unit (TB / TEG / TCCW) | Checkbox group (3 checkboxes) | Business Unit reference data | Zero or more may be ticked. **Not required** | Static – three fixed check boxes |

### 4. Document Search Fields

| Field Name | Field Type | Datasource | Business Validation | Static / API Source |
|---|---|---|---|---|
| Document Name | Dropdown (full width) | Documents created and held in Admin → Manage Documents | Single selection; defaults to N/A. Returns all Partners holding that Document under their Dealer Record | API – document reference data |
| Module | Dropdown (full width) | Modules created and held in Admin → Manage Modules | Single selection; defaults to N/A. Constrains the Document Name and Version lists to that Module | API – module reference data |
| Document Version | Dropdown | Version numbers held against the selected Document | Single selection, or N/A for all versions. **Must be a specific version (not N/A) to enable Super User bulk update** | API – version list for selected Document |
| Document Status | Dropdown | Document lifecycle status | Filters on Active, Pending, Superseded, Terminated or Aborted; N/A returns all statuses. **Must be set to Active to enable Super User bulk update** | Static – fixed lifecycle status list |
| Document Type | Dropdown | Document Type reference data | Single selection; defaults to N/A. Used to refine document results | Static / API – configured document type list |

### 5. Task Search Fields

| Field Name | Field Type | Datasource | Business Validation | Static / API Source |
|---|---|---|---|---|
| Task Definition | Dropdown (full width) | Task Definitions held in Admin → Manage Task Definitions | Single selection; defaults to N/A. Returns all Partners issued that Task | API – task definition reference data |
| Task Status | Dropdown | Task Statuses held in Admin → Manage (Task) Status | Optional; defaults to N/A (all statuses). Tasks at "Filed (Complete)" status cannot be bulk updated | API – task status reference data |
| Assigned to | Dropdown | CMD User register (Super Users / Contracts Team) | Optional; defaults to N/A. Restricts results to Tasks owned by that Contracts Team member | API – user reference data |

> **Not present on this screen:** *Task Type*, *Task Requester* and *Date Range* were listed in an earlier draft but do not appear on the Advanced Search page. Task Requester and Date Range belong to the **Task Wizard** screen (Section 5 of the source document).

### 6. Search Results & Termination Controls

| Field Name | Field Type | Datasource | Business Validation | Static / API Source |
|---|---|---|---|---|
| "All" select-all check box (results header) | Checkbox | Current Search Results set | Ticks/unticks every row in the current result page | Derived from search result rows |
| Dealer selection check box (per result row) | Checkbox | Current Search Results set | One or more Partners must be selected before Terminate, Supersede, Delete, Batch Initiate Task or Batch Manage Task can be actioned | Derived from search result rows |
| Display (results per page) | Dropdown | Fixed enumeration of page sizes | Defaults to 10. Controls how many result rows are shown | Static – configured page-size list |

### 7. Actions / Buttons

| Action | Field Type | Datasource | Business Validation | Static / API Source |
|---|---|---|---|---|
| Go (top right, next to global search) | Button | Global search text field | Submits the top right-hand corner search | API – dealer search query |
| Search | Button | Current filter selections | Executes the query using the entered criteria | API – search endpoint |
| Open | Button (per result row) | Selected Dealer Record | Opens the Dealer Record (or the relevant Document/Task tab). Users may only view one Dealer Record at a time | Navigation – API record fetch |
| Batch Manage Task | Button (disabled until rows selected) | Selected Partner/s | Super User only. Updates Task Status for tagged Partners, except Tasks at "Filed (Complete)" status | API – bulk task update |

| Batch Initiate Task | Button | Selected Partner/s | Super User only. Creates a new Task for each selected Partner | API – bulk task create |
| Delete | Button (disabled until rows selected) | Selected Partner/s | Super User only. Removes the selected record/s | API – delete endpoint |
| Supersede | Button | Selected Partner/s + specific Document Version | Super User only. Requires a specific Document Version and Document Status = Active | API – bulk document update |
| Terminate | Button | Selected Partner/s + Date Select value | Super User only. Confirmation prompt required. A terminated Dealer Record can return to Pending status if a new task is allocated and the executable contract document is awaiting signature | API – termination endpoint |
| Undo | Button (disabled until applicable) | Last actioned change | Reverses the preceding action | API – undo endpoint |
| Result paging arrows (◄ ►) | Button (pair) | Current Search Results set | Moves between pages of results, in line with the Display page size | Client-side / API paging |
| `<< Bottom` / `<< Top` | Hyperlink | Page anchors | Jumps to the bottom or top of the results page | Static – in-page anchor |
