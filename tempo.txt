Phase 1 (Weeks 1-3) — Python + Data Libraries ka detailed breakdown, Java background ke context me:

## Week 1: Python Core (Java se mapping karke seekho)

**Syntax basics (fast jaayega, bas Java se difference note karo):**
- Variables, data types (Java me explicit typing hai, Python dynamic — ye mindset shift important hai)
- Indentation-based blocks (no `{}`, no semicolons)
- `if/elif/else`, loops (`for`, `while`)
- Functions — `def`, default args, `*args`, `**kwargs` (Java overloading jaisa nahi hai, ye naya concept hai)

**Data structures (Java collections ka Python equivalent):**
- List (~ ArrayList), Tuple (immutable list), Dict (~ HashMap), Set (~ HashSet)
- List comprehensions — `[x*2 for x in list]` — ye Java me nahi hota, isko achhe se practice karo, AI code me har jagah milega
- Slicing (`list[1:5]`) — naya concept, important hai

**OOP in Python (concepts same hain Java se, syntax alag):**
- Classes, `__init__` (~ constructor), self (~ this)
- Inheritance, `super()`
- Dunder/magic methods (`__str__`, `__repr__`) — basic samajh lo

**Error handling:**
- `try/except/finally` (Java ke try-catch jaisa hi, bas syntax alag)

## Week 2: Python Ecosystem Essentials

- Virtual environments — `venv` ya `conda` (Java ke Maven/Gradle dependency isolation jaisa concept)
- `pip` aur `requirements.txt` (~ pom.xml/build.gradle)
- File handling (read/write CSV, JSON)
- Working with APIs — `requests` library (REST calls karna, JSON parse karna — ye tumhe already easy lagega)
- Lambda functions, `map()`, `filter()` — functional style, Java streams jaisa

## Week 3: NumPy + Pandas (AI/ML ka data backbone)

**NumPy:**
- Arrays (1D, 2D) — kyun list se better hain (vectorized operations)
- Array indexing, slicing, reshaping
- Basic math operations (element-wise ops, broadcasting concept)
- `mean`, `sum`, `std` jaise aggregate functions

**Pandas (ye sabse zyada use hoga):**
- Series aur DataFrame — inko samjho jaise SQL table ka Python version
- Reading data — `read_csv()`, `read_json()`
- Filtering rows, selecting columns (`df[condition]`, `df.loc`, `df.iloc`)
- `groupby()`, aggregations — SQL GROUP BY jaisa hi hai
- Handling missing data — `dropna()`, `fillna()`
- Merging/joining dataframes — SQL joins jaisa

**Skip karo (abhi ke liye):**
- ❌ Multithreading/async Python (backend me kaafi different hai Java se, but AI work me abhi zarurat nahi)
- ❌ Advanced decorators, metaclasses (deep Python internals — waste of time abhi)
- ❌ Django/Flask (FastAPI seedha seekhoge Phase 3 me)

**Practice tip:** Jab bhi koi concept seekho, ek chhota script likho jo real CSV file pe kaam kare (e.g., ek sample sales data lo, Pandas se filter/group karo). Passive video-dekhna se code likhna zyada retain hoga.

Phase 2 ke liye jab ready ho, batao.
